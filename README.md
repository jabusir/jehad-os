# Jehad OS

A durable personal AI control plane: structured state about Jehad's world, bounded
autonomous work with verification, memory that compounds, and the smallest possible
demand on human attention.

Status: Phase 0 (discovery & architecture). Source directive:
`~/Downloads/JEHAD_OS_BUILD_DIRECTIVE(1).md`.

- Phase 0 plan: [`docs/plans/phase0.md`](docs/plans/phase0.md)
- Architecture decisions: [`docs/adr/`](docs/adr/)
- Edge node (separate repo): `/Users/Shared/tito` (OpenClaw + Home Assistant)

Canonical state lives in PostgreSQL. No harness, model, or integration is the system
of record.
